# StratX Loot ESP for ROB RUN (free build)

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

Loot-only cut of the StratX build with value tiers and auto loot.

| Tier | Content | Default |
| --- | --- | --- |
| high | safes, rare drops | on |
| mid | armor, meds, ammo | on |
| low | generic crates | off |

## Auto loot

Opens crates in reach, priority list orders categories, ammo skippable. Delay slider 50-400 ms.

## Install

Admin loader, game, INSERT, set tier floor, F3 toggle.

## Troubleshooting

Auto loot stops: priority list emptied. Overload: tier floor high.

Item table version bound. Windows 10/11, Steam, EAC.
